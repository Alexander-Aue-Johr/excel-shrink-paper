# Companion manuscript snapshots

This directory contains companion working manuscripts for the two planned
ICDE 2027 submissions. They provide optional methodological context and identify
the boundary between the contributions. The main manuscripts describe the
methods, assumptions and evidence needed to assess their respective claims.

| File | Subject |
| --- | --- |
| `related-manuscripts/sheetshrink.pdf` | Workbook cleanup and preservation structures |
| `related-manuscripts/deltasieve.pdf` | Region selection, native rendering and retained comparison evidence |

These are working drafts, with provisional author blocks and incomplete final
evaluation. They are prepared for submission and are not described as accepted
or already under review. `manifest.json` records the file hashes, source hashes
and snapshot status. Replace both PDFs with the corresponding submitted versions
and update the manifest before the final artifact freeze.

For an artifact package, retain this README and `related-manuscripts/` at the
package root so the paths cited in the manuscripts resolve. Identify the code
revision, experiment configurations and result manifests separately when the
complete reproducibility package is frozen. These two PDFs alone do not form
the complete experimental artifact.

The submission form should disclose the related manuscripts and distinguish
their contributions. CMT identifiers, when available, complement the paper titles
and filenames. Reviewer access to a separate submission cannot be inferred from
an identifier alone. The final published citations and access links should be
updated to the actual publication or retained manuscript versions.
