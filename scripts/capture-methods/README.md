# DeltaSieve method panels

Run from the repository root with ReportLab, Pygments and pypdf installed.

```powershell
python scripts/capture-methods/render.py
```

The inventory is `papers/deltasieve/evidence/capture-development/snippets.json`.
It pins source anchors and identifies abbreviated illustrations. The renderer
reuses the XML atlas typography, embeds fonts, checks code text and rejects
raster PDF objects. LaTeX consumes the generated PDFs without Python.

The adjacent evidence README separates historical adapter results, failed trials
and current production scope. No Excel workload runs during figure generation.
